# Clpmart Android app
Expo React Native application. Install dependencies with `npm install`, set the API constant in `App.js` to your deployed API base URL, then run `npx expo start` and open Android.

Build an installable Android package with EAS after configuring your Expo account and Android application signing. The customer storefront and cart are included; seller onboarding and full account/order management are handled through the web console in this initial release.
